온라인 스크래치 ↔ 파이썬 변환기: pyScratch가 하는 일

      
pyScratch는 Scratch 3.0 프로젝트(.sb3)를 열고 모든 스크립트를 파이썬 스타일 코드로 보여 주는 무료 온라인 IDE입니다. .sb3 파일을 파이썬 코드로 수정한 뒤 브라우저 안의 480×360 무대에서 바로 실행하고, 일반 Scratch 에디터에서 열리는 .sb3 파일로 다시 저장할 수 있습니다. 반대로 처음부터 파이썬 스타일 코드를 작성하면 pyScratch가 Scratch 블록을 자동으로 생성해 줍니다. 스크래치에서 파이썬으로 넘어가는 학생과 블록·텍스트 코드를 함께 보여 주고 싶은 교사를 위해 설계되었습니다.

      
온라인에서 .sb3 파일을 열고 파이썬으로 변환하는 방법

      
    
        
  1. Scratch 에디터에서 「파일 → 컴퓨터에 저장하기」를 선택해 프로젝트의 .sb3 파일을 받습니다.
    2. 
        
  2. pyScratch에서 「파일 → .sb3 열기」를 누르거나 .sb3 파일을 페이지 위로 바로 끌어다 놓습니다.
    3. 
        
  3. 무대 아래 패널에서 스프라이트나 무대를 선택합니다. 코드 에디터에서는 스크립트가 파이썬으로 표시되고, 「Scratch 블록」 탭에서는 블록 트리로 볼 수 있으며 블록을 클릭하면 해당 코드 줄로 이동합니다.
    4. 
        
  4. 코드를 수정하고 초록 깃발(또는 Ctrl+Enter)을 눌러 무대에서 프로젝트를 실행합니다.
    5. 
        
  5. 「파일 → .sb3 저장」을 누른 다음 다운로드한 파일을 Scratch의 「파일 → 컴퓨터에서 불러오기」로 엽니다.
    6. 
      

      
「인스펙터 (.sb3)」 탭에서는 Scratch 온라인 제한(project.json 5 MB, 파일당 리소스 10 MB)을 점검하고 사용하지 않는 모양과 소리를 한 번에 정리할 수 있습니다.

      
파이썬 코드로 할 수 있는 것

      
이 코드는 각 함수가 Scratch 블록에 1:1로 대응하는 소형 파이썬 방언입니다: move(10), say("Hello!", 2), if touching("edge"):, for i in range(10):, while True: 등을 지원합니다. @when_flag_clicked나 @when_key_pressed("space") 같은 데코레이터는 이벤트 모자 블록이 되고, def는 나만의 블록을 정의하며(@warp는 화면 새로고침 없이 실행), score = 0은 모든 스프라이트 공용 변수, self.hp = 100은 이 스프라이트 전용 지역 변수가 됩니다.

      
동작, 형태, 소리, 이벤트, 제어, 감지, 연산, 변수와 리스트, 나만의 블록과 복제본은 물론 펜, 음악, 텍스트 음성 변환, 번역 확장 기능까지 지원합니다. 「API 레퍼런스」 탭에서 모든 명령어를 확인할 수 있으며 9개의 학습 템플릿(핑퐁, 미로, 클리커 게임 등)이 기본 예제로 제공됩니다.

      
알아둘 제한 사항

      
    
        
  • 완전한 표준 파이썬이 아닙니다: import, class, return, break, continue, lambda, try/except, with, f-문자열, **, 삼항 연산자 a if b else c는 지원되지 않으며 컴파일러가 이를 안내합니다.
    • 
        
  • 변환기가 아직 지원하지 않는 블록(예: 비디오 감지 또는 Makey Makey)이 포함된 스크립트는 프로젝트에 그대로 유지되어 변경 없이 저장되지만, 에디터에는 주석만 표시되며 코드로 수정할 수 없습니다.
    • 
        
  • pyScratch가 블록을 새로 생성할 때 기존 블록에 붙어 있던 주석은 저장 시 사라집니다.
    • 
        
  • 내장 무대는 Scratch 엔진 자체가 아니라 간소화된 시뮬레이터입니다: 충돌 판정은 근사치이며 어안(fisheye)·소용돌이(whirl) 효과는 그려지지 않고, translate()는 미리보기가 인터넷에 연결되지 않으므로 원문을 그대로 반환합니다. 최종 결과는 반드시 Scratch에서 확인하세요.
    • 
        
  • 컴파일러 오류 메시지, 블록 트리 라벨, 변환기 코드 주석은 우크라이나어, 영어, 폴란드어, 러시아어, 한국어 등 5개 언어로 현지화되어 있습니다.
    • 
      

      
개인정보 보호: 프로젝트는 브라우저를 떠나지 않습니다

      
pyScratch는 완전히 브라우저 내부에서 실행됩니다. .sb3 파일의 압축 해제와 생성은 모두 사용자 기기에서 이루어지며, 서버로 아무것도 업로드되지 않고 계정이나 로그인이 필요 없습니다. 페이지에서는 쿠키 없이 익명 방문 수만 집계합니다. 「공유」 버튼은 코드를 링크 자체에 담기 때문에 해당 링크를 받은 사람은 그 코드를 볼 수 있습니다.

      
자주 묻는 질문

      

        
스크래치 프로젝트를 온라인에서 무료로 파이썬으로 변환할 수 있나요?

        
네. pyScratch에서 .sb3 파일을 열면 각 스프라이트의 스크립트가 파이썬 스타일 코드로 바로 나타납니다. 설치나 회원가입이 필요 없는 무료 도구이며 MIT 라이선스로 오픈 소스 공개되어 있습니다.

        
Scratch를 설치하지 않고 온라인에서 .sb3 파일을 어떻게 여나요?

        
「파일 → .sb3 열기」를 선택하거나 파일을 페이지 위로 끌어다 놓으세요. 아무것도 설치하지 않고 스크립트를 코드와 블록으로 확인하고 무대에서 실행하며 리소스를 살펴볼 수 있습니다.

        
파이썬으로 .sb3를 수정한 뒤 다시 Scratch에서 열 수 있나요?

        
네. 코드를 수정한 다음 「파일 → .sb3 저장」을 선택하고 Scratch 3.0 에디터에서 「파일 → 컴퓨터에서 불러오기」로 다운로드한 파일을 열면 됩니다.

        
이 코드는 실제 파이썬인가요?

        
Scratch 블록을 바탕으로 만든 파이썬 스타일 언어입니다. 들여쓰기, if, elif, else, while, for i in range(n), def 등은 파이썬처럼 동작하지만 import, 클래스, return은 없으므로 일반 파이썬 인터프리터에서는 실행되지 않습니다.

        
내 프로젝트가 외부 서버로 업로드되나요?

        
아니요. 열기, 변환, 저장은 모두 사용자의 브라우저 안에서 처리되며 .sb3 파일은 기기 밖으로 나가지 않습니다.

        
pyScratch가 지원하지 않는 블록은 어떻게 되나요?

        
알 수 없는 블록이 포함된 스크립트는 프로젝트에 그대로 남아 저장된 .sb3 파일에 변경 없이 다시 들어갑니다. 코드 에디터에서는 주석으로 표시되며 해당 영역은 수정할 수 없습니다.

        
구버전 Scratch 2.0 (.sb2) 파일도 pyScratch에서 작동하나요?

        
아니요, Scratch 3.0 (.sb3) 파일만 지원합니다. 구버전 .sb2 프로젝트는 먼저 Scratch 3.0 에디터에서 연 뒤 다시 저장해 .sb3 파일로 변환하세요.
