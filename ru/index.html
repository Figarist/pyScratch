Scratch в Python онлайн: что умеет pyScratch

      
pyScratch — бесплатная онлайн-IDE, которая открывает проекты Scratch 3.0 (.sb3) и показывает каждый скрипт как код в стиле Python. Код можно редактировать, запускать на сцене 480×360 прямо на странице и сохранять обратно в файл .sb3, который открывается в обычном редакторе Scratch. Работает и в обратную сторону: пишете Python-подобный код с нуля — pyScratch сам собирает из него блоки Scratch. Инструмент сделан для учеников, которые переходят со Scratch на Python, и для учителей, которым удобно показать одну и ту же программу и блоками, и текстом.

      
Как открыть sb3 онлайн и перевести Scratch в Python

      
    
        
  1. В редакторе Scratch выберите «Файл → Сохранить на свой компьютер», чтобы получить файл .sb3 вашего проекта.
    2. 
        
  2. В pyScratch откройте «Файл → Открыть .sb3» или просто перетащите файл .sb3 на страницу.
    3. 
        
  3. Выберите спрайт или Сцену на панели под сценой. Редактор покажет скрипты этого объекта как Python-код, а вкладка «Блоки Scratch» — те же скрипты деревом блоков; клик по блоку переносит к его строке в коде.
    4. 
        
  4. Измените код и нажмите зелёный флажок (или Ctrl+Enter), чтобы запустить проект на сцене.
    5. 
        
  5. Выберите «Файл → Сохранить .sb3», а скачанный файл откройте в Scratch через «Файл → Load from your computer» (в русском Scratch этот пункт по-прежнему на английском).
    6. 
      

      
Вкладка «Инспектор (.sb3)» проверяет проект на лимиты Scratch (5 МБ для project.json и 10 МБ на один ресурс) и помогает удалить неиспользуемые костюмы и звуки.

      
Что умеет Python-код

      
Код — это небольшой диалект Python, где каждая функция соответствует блоку Scratch: move(10), say("Привет!", 2), if touching("edge"):, for i in range(10):, while True: и так далее. Декораторы вроде @when_flag_clicked или @when_key_pressed("space") превращаются в блоки-события, def создаёт собственный блок из раздела «Мои блоки» (@warp выполняет его без обновления экрана), score = 0 — переменная для всех спрайтов, а self.hp = 100 — переменная только для этого спрайта.

      
Поддерживаются категории «Движение», «Внешность», «Звук», «События», «Управление», «Сенсоры», «Операторы», «Переменные» со списками, «Мои блоки» и клоны, а также расширения «Перо», «Музыка», «Озвучивание текста» и «Перевод». Все команды собраны во вкладке «Справочник API», а девять учебных шаблонов (пинг-понг, лабиринт, кликер и другие) дают готовые примеры.

      
Честно об ограничениях

      
    
        
  • Это не полноценный Python: import, class, return, break, continue, lambda, try/except, with, f-строки, ** и выражение a if b else c не поддерживаются — компилятор прямо об этом сообщит.
    • 
        
  • Скрипты с блоками, которых конвертер пока не знает (например, Video Sensing или Makey Makey), остаются в проекте и сохраняются без изменений, но в редакторе виден только комментарий — редактировать их как код нельзя.
    • 
        
  • Комментарии, прикреплённые к блокам, которые pyScratch генерирует заново, при сохранении пропадают.
    • 
        
  • Встроенная сцена — упрощённый симулятор, а не движок Scratch: касания проверяются приблизительно, эффекты «рыбий глаз» и «вихрь» не отрисовываются, а translate() возвращает текст без изменений, потому что предпросмотр не выходит в интернет. Окончательный результат всегда проверяйте в Scratch.
    • 
        
  • Сообщения об ошибках компилятора и служебные комментарии, которые конвертер добавляет в код, пока только на украинском.
    • 
      

      
Приватность: проект не покидает браузер

      
pyScratch работает полностью в вашем браузере. Файл .sb3 распаковывается и упаковывается на вашем устройстве, ничего не загружается на сервер, регистрация не нужна. Страница только считает анонимные посещения без cookie. Кнопка «Поделиться» записывает ваш код прямо в ссылку, поэтому его увидит каждый, у кого есть эта ссылка.

      
Частые вопросы

      

        
Как перевести Scratch в Python онлайн бесплатно?

        
Откройте файл .sb3 в pyScratch — скрипты каждого спрайта сразу появятся как код в стиле Python. Инструмент бесплатный, не требует установки и аккаунта, а его исходный код открыт под лицензией MIT.

        
Как открыть файл sb3 онлайн без установки Scratch?

        
Выберите «Файл → Открыть .sb3» или перетащите файл на страницу. Вы увидите скрипты кодом и блоками, сможете запустить проект на сцене и посмотреть его ресурсы — ничего не устанавливая.

        
Можно ли изменить проект в Python и снова открыть его в Scratch?

        
Да. Отредактируйте код, выберите «Файл → Сохранить .sb3» и откройте скачанный файл в редакторе Scratch 3.0 через «Файл → Load from your computer».

        
Это настоящий Python?

        
Это язык в стиле Python, построенный из блоков Scratch. Отступы, if, elif, else, while, for i in range(n) и def работают как в Python, но нет import, классов и return, поэтому в обычном интерпретаторе Python этот код не запустится.

        
Загружаются ли мои проекты куда-нибудь?

        
Нет. Открытие, преобразование и сохранение происходят в вашем браузере, файл .sb3 не покидает ваше устройство.

        
Что происходит с блоками, которые pyScratch не поддерживает?

        
Скрипты с неизвестными блоками остаются в проекте и без изменений попадают в сохранённый .sb3. В редакторе кода они отмечены комментарием, и изменить их там нельзя.

        
Работает ли pyScratch со старыми файлами Scratch 2.0 (.sb2)?

        
Нет, только с файлами Scratch 3.0 (.sb3). Старый проект .sb2 сначала откройте в редакторе Scratch 3.0 и сохраните заново — получится файл .sb3.
